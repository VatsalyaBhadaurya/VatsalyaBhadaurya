<h2 align="center">⟡ The Thesis ⟡</h2>

<p align="center"><i>
In 1988 Hans Moravec noticed the cruel joke of robotics: chess is easy, perception is hard.<br/>
Four decades on, the joke still runs the field. I work on the hard half.
</i></p>

<p align="center">
I build <b>real-world humanoid robotics systems</b> — perception, behaviour, and embodied AI pipelines<br/>
deployed on <b>physical robots</b> using ROS2, Jetson, and VLM/VLA reasoning.<br/>
It started in grade 8. It became a practice in systems that must <b>survive</b><br/>
noisy sensors, tight memory and unforgiving latency. Simulators forgive. The real world doesn't.
</p>

(SmolVLA, π0, GR00T N1.x), built on llama.cpp for Jetson-class deployment —<br/>
the unglamorous layer where a policy stops being a research artifact and starts being something a robot can run.
