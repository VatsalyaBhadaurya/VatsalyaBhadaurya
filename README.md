<h2 align="center">⟡ The Thesis ⟡</h2>

<p align="center"><i>
In 1988 Hans Moravec noticed the cruel joke of robotics: chess is easy, perception is hard.<br/>
Four decades on, the joke still runs the field. I work on the hard half.
</i></p>

<p align="center">
I build <b>real-world AI systems for robots</b> — humanoid perception, behaviour intelligence,<br/>
and embodied decision-making that has to <b>survive</b> noisy sensors, tight memory and unforgiving latency.<br/>
Simulators forgive. Factory floors and living rooms don't.
</p>

<h2 align="center">⟡ Working Principles ⟡</h2>

<p align="center">

<b>03</b> &nbsp;Co-design the hardware and the software, or ship the compromise.<br/>
<b>04</b> &nbsp;If it only works in the demo, it doesn't work.
