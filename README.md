<h2 align="center">⟡ &nbsp;T H E &nbsp; T H E S I S &nbsp; ⟡</h2>

<p align="center"><i>
In 1988 Hans Moravec noticed the cruel joke of robotics: chess is easy, perception is hard.<br/>
Four decades on, the joke still runs the field. I work on the hard half.
</i></p>

<p align="center">
I build <b>real-world humanoid robotics systems</b>: perception, behaviour, and embodied AI pipelines<br/>
deployed on <b>physical robots</b> using ROS2, Jetson, and VLM / VLA reasoning.<br/>
It started in grade 8. It became a practice in systems that must <b>survive</b> noisy sensors,<br/>
tight memory and unforgiving latency. Simulators forgive. The real world does not.
</p>
